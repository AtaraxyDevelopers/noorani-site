Documentation

Still being written.

Noorani's documentation is being written alongside the v1.0 release — installation guides, keyboard shortcuts, calculation-method reference, troubleshooting.

In the meantime, we'd rather answer you personally than serve you a half-written wiki. Email support@nooranibrowser.com with any question — setup, features, privacy, whatever — and you'll hear back within 48–72 hours.

Early users get a direct line. It's how we want to work.

When v1.0 ships, this page will hold:

  • Installation and first-run guide for Windows, macOS, and Linux
  • Prayer-time configuration (locations, calculation methods, Asr juristic schools, high-latitude rules)
  • Qibla calibration notes
  • Content filter reference — what each sensitivity level actually does
  • Keyboard shortcuts
  • Import flow from Chrome, Edge, Firefox, Brave
  • Troubleshooting and FAQ deep-links

For release updates, check the roadmap or release notes.
