What changed.

A plain-English log of what's new, what's fixed, and what's coming up. No marketing speak.

v1.0.0-alpha April 2026

First public release. An early alpha for testing, feedback, and community shaping.

Included

  • Prayer times engine (6 calculation methods)
  • Qibla indicator
  • Hijri calendar (Umm al-Qura)
  • Tracker blocking (default on)
  • Quran quick-access
  • Content filter (3 sensitivity levels)
  • Ayah of the day (dismissible)

Known limitations

  • Builds are unsigned — expect OS warnings on first launch
  • Ramadan mode ships in v1.1
  • Full RTL + non-English UI ships in v1.1
  • No auto-update in alpha — check GitHub for new builds manually

How we version

Noorani uses semantic versioning (MAJOR.MINOR.PATCH). Major versions are reserved for changes that alter the browser's default behaviour in a way that might surprise existing users. Minor versions add features. Patch versions fix bugs.

Each release entry includes an SHA-256 checksum for every signed artifact, a list of bundled Chromium security fixes, and any changes to default settings.
